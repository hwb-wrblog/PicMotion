极简画影

图片和视频都能生成：写中文 → 点「生成」，风格和参数我来配。
幅度越小越贴近原图（保画风用 0.3-0.45），越大改动越多（换风格用 0.6-0.8）
选了控制方式 = 用参考图当「结构草图」重新画 —— 构图保留、内容和光线按提示词换； 不选 = 传统图生图（越像越保留原图，光影很难改）。
深度/姿态/线稿首次使用会下预处理器权重（走镜像），第一次会慢一点。
用「原图 + 掩码」补：原图那块不会被改动，只在外面生成新内容。 已挂扩图专用 inpaint ControlNet，接缝 / 光照 / 背景会延续原图。
实测结论（512×768 半身图 → 画布 512×1280）：
・不勾「缩小」：接缝干净，但腿被压扁、脚出不来（人物占满画布，没空间了）
・勾上「缩小」：完整全身（牛仔裤 + 球鞋），接缝看不出，背景连贯 ← 补全身用这个
提示词请把要补的东西 + 整体都写上（例：全身照，牛仔裤，双腿，白色运动鞋，站在水泥地面上，写实摄影）。
Wan2.2 5B：写了提示词就是文生视频；放了参考图就用它当**首帧**（图生视频）。
参数跟官方模板一致：uni_pc / simple / CFG 5 / shift 8 / 24fps。
